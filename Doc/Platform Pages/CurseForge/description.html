🛌 Vanilla Outsider: Bed Chat Hider

"A clean, distraction-free sleeping view with a single click."

1 Jar 1 Version Policy: I build 1 dedicated JAR for each Minecraft version (e.g. MC 26.2, MC 26.3, 1.21.1, 1.20.1). Please download the exact build that matches your Minecraft installation.

Vanilla Outsider: Bed Chat Hider is a client-only Fabric mod that adds a simple "Hide Chat" / "Show Chat" toggle button next to the "Leave Bed" button while sleeping.

Collection Notice: Unlike other mods in the Vanilla Outsider Collection (such as True Sleep), Bed Chat Hider is 100% client-only, requires zero configuration files or GameRules, and has zero runtime dependencies (does NOT require Fabric API)!

Client-side sovereignty: You can safely install Bed Chat Hider on your client and join ANY vanilla, Fabric, Paper, Spigot, or Forge server without requiring the mod on the server.

✨ Features

🎞️ Clear World View

Hides the chat input background fill, suggestions, and the chat history log completely when toggled with the button while resting.

With True Sleep Mod (Accelerated Time-Lapse View)

When paired with the True Sleep companion mod, the dark sleep vignette is removed, allowing you to watch the sky fly by in real-time time-lapse without UI overlays blocking the view!

Without True Sleep Mod (Vanilla Dark Sleep Overlay)

Without the True Sleep mod, the vanilla black vignette sleep darkening is still present, but the chat overlay is hidden.

  • Chat Shown (Vanilla):

💤 Session-Based State

Tracks your toggle preference in-memory. The preference is maintained during your current game session so you don't have to keep clicking it every night.

🛡️ Input Blocker

Safely intercepts and blocks keyboard typing, scrolling, and clicking on the invisible chat log when the chat is hidden, ensuring that only the standard UI buttons are interactive and Escape closes the screen naturally.

🔧 Configuration

This mod is plug-and-play with zero config files or GameRules. The toggle state is stored purely in-memory during your current session. There are no configuration screens or external GUI dependencies required.
